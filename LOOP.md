## The hard rule: visuals are 100% code
- **Every pixel on screen is generated by code**: Remotion/React, SVG, CSS, Canvas, WebGL/GLSL shaders, three.js
  (`@remotion/three`), procedural noise/particles, kinetic typography, ffmpeg filters.
- **No** AI images, AI video, stock footage, photos, or frames copied from reference reels. Fonts and icon/vector
  libraries are allowed (they are code/vector data). Textures must be procedural (noise, grain, gradients), not downloaded images.
- **Audio may come from anywhere**: AI voice (Treg TTS), AI music (Treg Lyria), code-synthesised SFX (ffmpeg/sox/WebAudio), CC0 sound libraries.
- Any make that breaks this rule is invalid and is not scored.

## Goals
1. **Make best-in-class reels in code** that hold up next to the reference reels end to end: hook, story, visuals, motion and cut rhythm, sound, captions.
2. **Understand virality well enough to program it.** Every iteration adds at least one *new, evidenced* finding, and that finding becomes a rule the next make must apply.
3. **Unblock yourself.** Every blocker gets a workaround and a log entry, and the loop continues. Never wait on the owner.

## Iteration (target 45–75 min, ~8–12 iterations)
Run Track A and Track B in parallel (subagents), then integrate.

### Track A: make (code visuals + any audio)
1. **Pick the target.** Choose the next reference reel by virality × code-feasibility (tiers below). Alternate between
   (a) **rebuilding** a specific reference reel and (b) an **original** reel that applies the playbook. The originals test whether the rules work.
2. **Break it down.** Write `makes/<id>/spec.md`: scene list with timings, the hook (first 3 s: line + visual), the
   voiceover script, caption style, music/SFX cues, palette and look. For each visual element in the reference, give its
   **code translation**: how it will be drawn (SVG illustration, shader, particles, type, 3D primitive, etc.).
3. **Build.**
   - Audio first: voiceover via TTS with word timestamps, then music, then code SFX. The audio timings drive the cuts.
   - Visuals in Remotion: reusable components in `remotion/src/lib/` (captions, film treatment, parallax rig,
     SVG character kit, shader backgrounds, transitions, Devanagari text).
   - Render at 1080×1920, 30 fps, with loudness normalised to about −14 LUFS.
4. **Grade.** Run `scripts/analyze_reel.py` on both reels, plus side-by-side frame sheets. A **fresh grader subagent**
   that did not build the reel scores it 1–10 on: hook, story clarity, visual craft, motion/cut rhythm, audio mix,
   captions/typography, and "would this stop the scroll next to the reference". The grader also names the single
   weakest frame and the single weakest second.
5. **Fix and re-render.** Fix the 2–3 biggest gaps, re-render and re-grade. Stop after 3 versions per reel, then mark
   it `hard` and log what blocked it.
6. **Log.** Write to `makes/LOG.md`: version, per-dimension scores, what changed, audio spend.
   Copy the best version to `renders/best/`.

### Track B: virality
1. Advance one research question per iteration. Examples: hook type vs views, first-frame text, duration, cut rate,
   voiceover vs music-only, language, story shape, series effects, posting time, CTA, caption density, loop endings.
2. Data: `data/creators/*.csv` (views, likes*, comments, duration, date), the per-reel analysis in `analysis/`, and the
   labels in `data/labels.csv`. Metric: `log(views / creator median)`. *Likes = 3 means likes are hidden; exclude those.
3. Write each finding with its evidence (n, effect size, examples, caveats) to `research/03_virality_analysis.md`, then
   turn it into a rule in `research/virality_playbook.md`. Rules that can be checked go into a code checklist
   (`scripts/playbook_check.py`) that Track A runs before rendering.

### Integrate (end of every iteration)
Update `TASKS.md`, `DECISIONS.md` and `makes/LOG.md`, then commit and push.
Every iteration must change the playbook, the pipeline code, or both.

## Code-feasibility tiers (replace the AI-asset tiers in `research/02_feasibility_triage.md` for this loop)
| Tier | What the reference uses | How we rebuild it in code |
|---|---|---|
| **C1** | motion graphics, kinetic type, title cards, infographics, maps | direct rebuild in Remotion |
| **C2** | illustrated stills, Ken Burns, parallax, flat or stylised art | SVG/vector illustration built from primitives, layered parallax, procedural textures |
| **C3** | cinematic AI stills or video, 3D renders, painterly art | stylised substitute: three.js/shader scenes, silhouettes, light rays, particles, "shadow-play" or "ink" look. Keep the story, hook and pacing; change the visual style |
| **C4** | real people on camera, the creator's own face, real-event footage | study only: transfer the hook, structure and pacing into a C1–C3 original |

## Getting better each iteration (checked, not hoped)
- The newest make must beat the previous best on at least one grading dimension, and must not regress more than 1 point on any other.
- Each pipeline improvement becomes a reusable component or script, not a one-off.
- Each virality finding must be new: check `research/03_virality_analysis.md` first.
- At least every 3rd iteration, re-grade the current best against the newest playbook, so old makes are judged by the new rules.

## Budget (Treg, audio only)
- Expected cost per make: voiceover ≈ $0.01–0.10 and music ≈ $0.04–0.08, so about $0.15 per version and about $0.40 per
  reel including fixes. Ten hours ≈ $3–5.
- Run `mcp__Treg__balance` before each iteration and log spend in `DECISIONS.md`.
- If the balance would drop below $0.10, switch to Gemini TTS (≈ $0.002 per 10 s), reuse earlier music beds, and
  synthesise music in code. Never stop for budget.

## Blocker policy
- If a tool call is refused or prompts, skip that step, log a `BLOCKER:` entry in `DECISIONS.md` with the workaround tried, and continue.
- Instagram 429: back off, use the reels already downloaded plus the CSV stats, and retry later. One downloader at a time.
- Render too slow: lower the concurrency or resolution for drafts; render final quality only for the graded version.
- Missing font or library: install it from npm (for example `@remotion/google-fonts` for Devanagari); never use image assets.
- Container restart: everything needed is in git. Re-install the tools, re-run `scripts/download_reels.sh`, and continue from `TASKS.md`.
